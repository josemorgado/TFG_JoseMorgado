# 📦 Release v1.0.0 – Primera versión estable

**Proyecto:** Alcalde Escúchame
**Autor:** Jose María Morgado Prudencio
**Tipo:** Trabajo Fin de Grado
**Fecha de la release:** 9 de abril de 2026
**Versión:** v1.0.0

---

## 🧩 Descripción general

La versión **v1.0.0** representa la primera versión estable del proyecto **“Alcalde Escúchame”**.
Este punto marca el momento en el que el sistema alcanza su **forma funcional completa**, incorporando todas las entidades, flujos y componentes necesarios para cumplir los objetivos definidos en el Trabajo Fin de Grado.

A partir de esta versión, el proyecto deja de centrarse en la implementación de funcionalidades principales y pasa a una fase orientada a la **validación, mejora y refinamiento** del sistema.

---

## ✅ Estado del proyecto en v1.0.0

En esta release, el proyecto cuenta con:

- Backend desarrollado con **Django REST Framework**, incluyendo:
  - Modelos de datos completos y relacionados.
  - Endpoints funcionales para la gestión de usuarios y contenido.
  - Arquitectura preparada para entorno de producción.

- Frontend desarrollado con **React + Vite**, incluyendo:
  - Interfaz funcional para los usuarios.
  - Comunicación con la API mediante peticiones HTTP.
  - Manejo básico de errores y estados.

- Repositorio organizado con control de versiones mediante **Git**, utilizando:
  - Rama `develop` para el desarrollo.
  - Rama `main` para versiones estables.
  - Etiquetado de versiones mediante tags.

---

## 🚀 Objetivo de esta release

El objetivo principal de la versión **v1.0.0** es servir como **base estable** para:

- El **despliegue público** del proyecto.
- La **realización de pruebas en un entorno real**.
- La **obtención de feedback por parte de usuarios**.
- La **detección de errores no observados en desarrollo**.

Esta versión será utilizada como referencia para comparar la evolución del proyecto en versiones posteriores.

---

## 🧪 Fase de pruebas y validación

A partir de esta release, se inicia una fase de pruebas que incluye:

- Uso real de la aplicación por parte de usuarios.
- Identificación de errores funcionales y de usabilidad.
- Recogida de sugerencias de mejora.
- Análisis del comportamiento del sistema en un entorno no controlado.

Los resultados obtenidos durante esta fase podrán dar lugar a:
- Correcciones de errores (releases de mantenimiento).
- Mejoras incrementales de funcionalidad.
- Ajustes en la experiencia de usuario.

---

## 🔄 Evolución futura

Las versiones posteriores a la **v1.0.0** se centrarán principalmente en:

- Corrección de bugs detectados.
- Mejoras de usabilidad.
- Optimización del rendimiento.
- Refinamiento de funcionalidades existentes.

No se contemplan cambios estructurales mayores, ya que la arquitectura base del proyecto queda definida en esta versión.

---

## 🏁 Conclusión

La release **v1.0.0** establece un hito fundamental dentro del desarrollo del proyecto, al consolidar una versión estable, funcional y preparada para su evaluación real, cumpliendo con los objetivos planteados en el Trabajo Fin de Grado.
